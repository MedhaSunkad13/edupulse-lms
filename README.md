EduPulse – Learning Management System

EduPulse is a web-based Learning Management System (LMS) built using **Python, Django, Bootstrap, and MySQL**. It provides a platform for students to access courses, view learning materials, watch lectures, download notes, submit assignments, and track their learning progress.

🚀 Features

- User authentication and authorization
- Student profile management
- Course and subject management
- Course enrollment
- Access to course learning materials
- Video lectures
- Downloadable PDF notes
- Assignment submission
- Learning progress tracking
- Responsive user interface using Bootstrap

🛠️ Tech Stack

Backend
- Python
- Django
- Django ORM

Frontend

- JavaScript

Database
- MySQL
